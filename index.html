📚 BookNest Library Management System

BookNest is a simple digital library management system designed to make everyday library operations easier and more organised.

Our Purpose

The main purpose of BookNest is to maintain book records, manage student memberships, issue books and record book returns efficiently.

Our Main Features

• Book catalogue and search
• Adding new books
• Book issue and return management
• Student member records
• Automatic availability updates

Technologies Used

HTML5, CSS3, JavaScript and Browser LocalStorage.
